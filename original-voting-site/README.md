# 原投票站的脱敏代码

这是从所有者本地工作区复制的源码，用于理解事故中的 `GET /api/results`、内部 `caches.default`、D1、新票人机校验、IP 投票限制和前端轮询。它不是完整生产备份，也不是已经与高峰期线上版本唯一对齐的 release。

**新项目优先看旁边的 [快照示例](../voting-snapshot/README.md)。** 这份历史代码的结果 GET 仍然进入 Worker；内部缓存并未消除入口调用费。保留这个行为是为了复盘。

## 本地检查

需要 Node.js 22.13+（或 24+），测试使用 Node 内置 SQLite，依赖版本由 lockfile 固定：

```sh
npm ci
npm run check
npm test
```

这些测试使用合成 IP、假令牌和桩接口，不验证真实支付收款、CDN/WAF 或云端计费。支付模块是原项目开发中的代码，默认关闭，没有商户凭据，也没有完成可供生产使用的收款验收。

可单独查看静态页面：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

页面 API 指向本机 `127.0.0.1:8787`，没有运行本地 API 时无法获取票数。Turnstile 使用官方测试 sitekey；不应把测试 key 用于公开服务。静态演示不是已经工作的云端服务。

## 脱敏范围

- 删除 account ID，D1 ID 替换为全零占位值；默认、预览和自定义路由关闭。
- 前端 API 改成回环地址，支付、公开日志默认关闭，部署脚本移除。
- 原绘画和广告图标替换为本仓库新写的 SVG 占位图；原页面文字及结构保留用于对照，广告跳转替换为 `example.com`。
- 保留 SQL schema 与迁移，但不附带数据库内容、真实 IP、密钥、商户资料或原始日志。

[source-manifest.json](source-manifest.json) 记录所复制文件在脱敏前的哈希与改动清单，用于版本核对；它不是线上版本认证。哈希不包含文件内容。没有修改原站代码或云资源。

本文没有建议重新部署历史方案。若要研究本地 Worker，需要另外安装 Wrangler 并只使用 `--local`，创建本地测试库和所需桩配置；生产入口的配置和成本必须重新审查。
